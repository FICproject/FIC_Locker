# DocScan Cloud — Admin Suite

- `Admin_Website/` — React + TypeScript + Tailwind CSS + Recharts Admin Dashboard Console
- `mobile/` — React Native CLI + TypeScript + React Navigation Admin Mobile App
- `../backend/` — Single shared Node.js + Express + MongoDB backend (used by Admin Website, Admin Mobile App, and the User Mobile App)

## Quick Scripts

- `start-web.bat` — Starts the shared backend API and Admin Website dev server
- `start-all.bat` — Starts the shared backend API, Admin Website, and React Native Metro bundler
