# DocuScan User Mobile Application - Backend Integration Report

## 1. Overview
The DocuScan User Mobile Application has been constructed according to the PRD specifications, visual design mockups, and client requirements under the `user/` workspace.

## 2. API Contract & Integration Endpoints Expected

The DocuScan User App expects the following backend API endpoints on `http://localhost:5000/api/v1` (or production base URL):

### A. Authentication & Session Management
- `POST /api/v1/auth/register`: Register new user (`name`, `email`, `password`, `phone`)
- `POST /api/v1/auth/login`: Authenticate user (`email`, `password`)
- `POST /api/v1/auth/send-otp`: Dispatch OTP for verification (`identifier`, `type`)
- `POST /api/v1/auth/verify-otp`: Validate OTP
- `POST /api/v1/auth/forgot-password`: Send password reset link/OTP
- `POST /api/v1/auth/reset-password`: Reset password
- `POST /api/v1/auth/refresh-token`: Exchange refresh token for fresh short-lived access token
- `GET /api/v1/auth/me`: Retrieve current authenticated profile & storage quota
- `POST /api/v1/auth/logout`: Invalidate session

### B. Document Management & Private Storage
- `GET /api/v1/documents`: List user's documents with filters (`category`, `folderId`, `fileType`, `search`, `sortBy`)
- `GET /api/v1/documents/:id`: Retrieve single document metadata
- `POST /api/v1/documents/upload-auth`: Request short-lived signed upload URL (Private S3/Cloud Storage workflow)
- `POST /api/v1/documents/:id/confirm`: Confirm successful upload & trigger backend verification
- `GET /api/v1/documents/:id/download`: Generate short-lived download URL (no permanent public URLs)
- `PATCH /api/v1/documents/:id/favourite`: Toggle favorite flag
- `PATCH /api/v1/documents/:id/archive`: Archive document
- `PATCH /api/v1/documents/:id/restore`: Restore archived document
- `PATCH /api/v1/documents/:id/move`: Move document between folders
- `PUT /api/v1/documents/:id`: Update document metadata (name, category, tags, notes, expiryDate)
- `DELETE /api/v1/documents/:id`: Permanently delete document and storage blob

### C. Folders & Categories
- `GET /api/v1/folders`: List user folders
- `POST /api/v1/folders`: Create folder / subfolder
- `PUT /api/v1/folders/:id`: Rename folder
- `DELETE /api/v1/folders/:id`: Delete folder
- `GET /api/v1/categories`: Retrieve standard document categories

### D. Storage Management
- `GET /api/v1/storage/info`: Return current plan, quotaBytes, usedBytes, availableBytes, failedUploadCount

### E. Reminders
- `GET /api/v1/reminders`: List upcoming document expiration reminders
- `POST /api/v1/reminders`: Set reminder interval for document
- `DELETE /api/v1/reminders/:id`: Remove reminder

### F. Subscriptions & Payments
- `GET /api/v1/subscriptions/plans`: List available subscription tiers
- `GET /api/v1/subscriptions/current`: Retrieve active subscription
- `POST /api/v1/subscriptions/upgrade`: Initialize subscription checkout session
- `POST /api/v1/subscriptions/cancel`: Cancel recurring subscription

### G. Support Tickets
- `POST /api/v1/support/tickets`: Create support issue
- `GET /api/v1/support/tickets`: List user support tickets
